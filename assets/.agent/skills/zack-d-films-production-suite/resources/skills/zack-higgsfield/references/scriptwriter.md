# Zack Scriptwriter Reference

## Target

Default 28–32 seconds, approximately 75–85 words. Use five beats:
**Myth → Twist → Mechanism A → Mechanism B → Kicker.**

## Draft rules

- Open with a concrete question, impossible-seeming fact, or familiar belief.
- Reveal the reversal early enough to reward attention but leave the mechanism
  unresolved until the middle.
- Each mechanism sentence must describe something visible: force, motion,
  pressure, distance, material, sequence, or consequence.
- End by reframing the opening, not by adding an unrelated fact.
- Preserve uncertainty when sources disagree.

## Rewrite pass

1. Remove “maybe,” “basically,” “actually,” and similar padding unless needed for
   factual accuracy.
2. Replace vague scale words with concrete quantities or comparisons.
3. Delete adjectives that do not change a renderable image.
4. Prefer active verbs and short sentences.
5. Read aloud; aim around 2.5–2.8 words per second.
6. Ensure every sentence maps to a planned visual beat.
