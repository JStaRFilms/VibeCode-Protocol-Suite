# Worked Shape Example — Trojan Horse

This is an output-shape example, not a factual source.

## Angle

Everyone imagines soldiers simply hiding inside a giant horse, but the real
challenge was not concealment alone: the object had to survive transport, evade
inspection, and create access at the right moment.

## Five beats

1. Myth: a hollow horse somehow fooled an entire city.
2. Twist: hiding men was the easy part.
3. Mechanism A: structure and wheels had to carry the load.
4. Mechanism B: timing and gate access mattered more than size.
5. Kicker: the “weapon” worked because it changed human decisions before battle.

## Block shape

- Block 1: familiar horse reveal, cutaway showing hidden volume, macro wheel/axle.
- Block 2: gate clearance, guards inspecting, green outline on structural path.
- Block 3: deadpan reveal, red path to gate mechanism, kicker image.
