1. Executive Summary & Lean Unified Architecture Fit

Our project operates under the Lean Unified Skills Architecture (docs/features/Lean_Unified_Skills_Architecture.md). In agentic harnesses like Antigravity, Claude Code, and Windsurf, every top-level skill description is injected directly into system prompt context on every single turn.

Token Budget Protection Law:

Importing all 44 P-Stack skills flat into the root skills directory would inject over 7,500 additional tokens into every single agent turn, pushing the system past prompt limits and causing the harness to silently drop skills.

❌ Naive Flat Import (Broken)
  • 44 flat top-level directories discovered
  • +7,500 to +12,000 prompt tokens per turn
  • System context saturation & silent skill drops
  • No category grouping or routing
✅ Lean Unified Import (Compliant)
  • Bundle 21 principles into 1 atomic suite (engineering-principles/)
  • Merge functional tools into existing suites (agent-engineering, dev-workflows, web-dev-standards)
  • Top-level prompt discovery count: +1 to +3 max
  • Zero context bloat; sub-skills read on demand via view_file

AGENTS.md Compliance Standard

Per AGENTS.md, all imported skills must adhere to two hard requirements:

  1. Invocation Triggers: The description must be phrased as an invocation rule starting with Use when [user wants to do X]... (maximum 2 sentences).
  2. Frontmatter Provenance: Frontmatter must specify author: P-Stack, coauthored: J StaR Films / Takomi, and version: X.X.X.

4. The 21 Principles Suite: Packaging & Router Architecture

P-Stack includes 21 atomic engineering principles. Each principle is a tightly-written markdown guideline targeting specific failure modes (e.g. boundary validation, state serialization, idempotent operations, laziness, root cause fixes).

The Engineering Principles Atomic Umbrella Suite:

Rather than polluting the root discovery catalog with 21 separate skills, we package them as a single top-level suite: assets/.agent/skills/engineering-principles/. The top-level SKILL.md acts as an intelligent router index, allowing the agent to view any specific principle on demand via view_file.

5. Key Workflows & Ecosystem Flows to Adopt

Several P-Stack skills represent multi-step systemic workflows that substantially level up Takomi's agentic lifecycle:

1
The 7-Evidence MCP Archaeology Flow (why + how + teach)

When an engineer asks why a system is built a certain way or why a regression happened, why queries up to 7 evidence categories in parallel (git blame, issue trackers, documentation, chat logs, metrics, error trackers, analytics). Combined with how (runtime mechanics) and teach (plain explanation synthesis), this gives Takomi superhuman context onboarding.

2
The Self-Generating Verification Loop (create-verification-skill + maintain-verification-skill)

Instead of relying on generic test guesses, when an agent lands in any repo, it runs create-verification-skill to generate a tailor-made, repo-specific verify harness that exercises the exact local commands, dev servers, and test runners. When pipelines change, maintain-verification-skill updates it automatically.

3
The Continuous Reflection & Skill-Evolution Loop (reflect)

After major coding sessions or failed tasks, running reflect spawns 3 review subagents to audit the transcript. It identifies friction, tool misuse, or missed edge cases, and directly proposes or applies patches to the corresponding skill markdown files. The skill ecosystem becomes self-healing and self-improving.

4
The Reviewable Autonomous Decision Trail (show-me-your-work)

During long autonomous runs or overnight executions, the agent maintains a structured TSV decision log (timestamp, action, rationale, evidence, risk, outcome). When a human engineer reviews the PR or wakes up, they can instantly audit every choice without wading through massive transcript logs.

5
The Blind-Judged Competitive Tournament (arena)

When designing a critical algorithm or refactoring complex logic, arena spawns N parallel candidate implementations, hides the author/model identities, and spawns an independent judge agent to score each approach against explicit criteria before picking a winner or grafting the best parts together.

6
Instant Machine Migration & Context Reconstruction (recall)

Fulfills the core personal goal stated in AGENTS.md: when moving to a new computer or resuming after a weekend, recall synthesizes uncommitted state, git commits, open tasks, and recent transcripts into a 30-second context briefing.
